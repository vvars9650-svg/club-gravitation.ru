# ГРАВИТАЦИЯ V2

Новая многостраничная версия сайта клуба «ГРАВИТАЦИЯ».

## Публикация

- `main` — опубликованная версия V2 на GitHub Pages.
- `v2` — рабочая ветка V2.
- `v1` — архив первой версии сайта.

## Структура

- `/` — главная
- `/about/` — о клубе
- `/events/` — мероприятия и календарь
- `/founders/` — основатели
- `/apply/` — заявка
- `/assets/brand/` — фирменный знак
- `/assets/images/` — изображения
- `/assets/css/` — общие стили
- `/assets/js/` — общая логика
- `/data/events.json` — данные мероприятий

Дизайн и содержание страниц утверждаются поэтапно.
