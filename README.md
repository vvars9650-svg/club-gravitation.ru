# Гравитация — клуб встреч

Первая рабочая версия лендинга клуба «Гравитация».

## Что внутри

- `index.html` — лендинг
- `styles.css` — адаптивная дизайн-система
- `app.js` — навигация и отправка заявки
- `privacy.html` — рабочая версия политики конфиденциальности
- `assets/` — визуалы, собранные из утверждённого макета
- `apps-script/Code.gs` — Google Apps Script для записи заявок в Google Sheets
- `.github/workflows/pages.yml` — публикация на GitHub Pages
- `CNAME` — домен `club-gravitation.ru`

## Подключение Google Sheets

1. Открыть Google Sheet `1. База участников — Google Sheets`.
2. `Расширения → Apps Script`.
3. Вставить содержимое `apps-script/Code.gs`.
4. `Развернуть → Новое развёртывание → Веб-приложение`.
5. `Выполнять от имени: Я`.
6. Доступ: `Все`.
7. Скопировать URL, заканчивающийся на `/exec`.
8. В `app.js` вставить URL в `CONFIG.endpoint`.
9. Сохранить изменение.

До подключения Apps Script форма сайта переводит пользователя на резервную Google Form.

## GitHub Pages

Откройте `Settings → Pages → Build and deployment → Source: GitHub Actions`.

После этого push в `main` публикует сайт.

## Домен

В репозитории есть `CNAME` с `club-gravitation.ru`. DNS домена настраивается на GitHub Pages после первой успешной публикации.

## Важно

`privacy.html` сейчас является рабочим MVP-текстом, а не финальным юридическим документом. До платного трафика нужно добавить сведения о фактическом операторе персональных данных и проверить юридическую часть.
