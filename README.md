# ГРАВИТАЦИЯ V5

Адаптивный многостраничный сайт клуба.

Страницы: главная, о клубе, мероприятия, основатели, заявка, политика конфиденциальности.

Брендовая система: Manrope, #0D0D0F / #1B1B1F / #2F2F33 / #D4AF7A / #F1D6A6 / #F7F4EE.

## Релизный кандидат: Legal 2.3

RC использует утверждённые 14.10.2026 `PPD-2.3`, `CONSENT-PD-2.3`, `FORM-2.3`, заголовок `Idempotency-Key` и два независимых legal-факта. История и повторы 2.2 сохранены. Сборки по умолчанию `PUBLIC_BLOCKED`; production-кандидат требует явного режима и точного PROD API. Документы начинают применяться при фактической публикации; PROD в этой работе не менялся. План: [activation HANDOFF](docs/ACTIVATION-2.3-HANDOFF.md).

Обработчик `api/application.js` не подключён к Yandex Cloud/YDB и отказывает в любом режиме, кроме `APPLICATION_MODE=TEST`. Для проверок используйте только синтетические данные. Реальные персональные данные и облачные реквизиты в репозиторий не добавляются.

## Правила хранения и версионирования

Этот репозиторий является единственным источником истины для исходного кода сайта клуба «ГРАВИТАЦИЯ».

- Вся активная разработка сайта ведётся только в GitHub.
- Исходный код, структура страниц, стили, изображения, конфигурация без секретов и история изменений хранятся здесь.
- Рабочие копии исходников сайта не дублируются в Google Drive.
- Google Drive используется для проектной, юридической, маркетинговой и управленческой документации.
- После перехода проекта на Яндекс Диск завершённые крупные версии сайта архивируются туда в виде слепков/релизов.
- GitHub остаётся мастер-хранилищем кода и после перехода на Яндекс.
- Секреты, API-ключи, токены и персональные данные участников в репозиторий не помещаются.

## Версионирование

- `main` — стабильная версия сайта.
- Крупные законченные версии фиксируются тегами/релизами: `v1.0`, `v2.0`, `v3.0` и т. д.
- Рабочие изменения по возможности выполняются в отдельных ветках и объединяются после проверки.

## Архивирование

После завершения крупного релиза создаётся архивный слепок версии для хранения в Яндекс Диске. Архив на Яндекс Диске не заменяет Git-историю и не используется для текущей разработки.
