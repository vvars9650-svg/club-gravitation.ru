# ГРАВИТАЦИЯ V2

Чистая архитектура второй версии сайта клуба.

## Статус

Черновик. Не публиковать на GitHub Pages до отдельного решения.

## Структура

- `/` — Главная
- `/about/` — О клубе
- `/events/` — Мероприятия
- `/founders/` — Основатели
- `/apply/` — Заявка
- `/assets/` — общие стили, скрипты и будущие изображения
- `/data/events.json` — источник данных для анонсов мероприятий

## Правила работы

1. `main` — действующая опубликованная V1.
2. `v1` — замороженный снимок V1.
3. `v2` — новая версия в разработке.
4. V2 не подключается к публикации до финального согласования.
5. Содержание и дизайн страниц разрабатываются поэтапно.
