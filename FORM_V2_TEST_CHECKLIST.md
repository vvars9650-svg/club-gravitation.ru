# Гравитация — регрессионный чек-лист анкеты V2

Перед переносом V2 на главную страницу все пункты должны пройти на Desktop Chrome и Android Chrome.

## Структура
- [ ] 6 шагов: Контактная информация → Фотография → О вас → Знакомства → Формат встреч → Проверка
- [ ] Нет цифр в названиях разделов
- [ ] Нет внутренних подзаголовков
- [ ] Красная полоса прогресса
- [ ] На первом шаге только «Далее»
- [ ] На шагах 2–5 «Назад» + «Далее»
- [ ] На последнем шаге нет «Далее»: только «Назад» и «Отправить заявку»
- [ ] Можно вернуться к уже пройденному разделу

## Контакты
- [ ] Возраст: выпадающий список 25–52
- [ ] Города ЮФО: выпадающий список по алфавиту
- [ ] Для города не Краснодар появляется обязательный вопрос о возможности посещать Краснодар
- [ ] Телефон принимает только +7 и 10 цифр, визуальная маска +7 999 999-99-99
- [ ] Некорректный телефон не пропускается
- [ ] Email необязательный, но некорректный email не пропускается

## Фото
- [ ] Фото обязательно
- [ ] Desktop: работает выбор файла
- [ ] Desktop: работает drag & drop
- [ ] Android: работает выбор из файлов/галереи
- [ ] После выбора показывается превью
- [ ] JPG/PNG/WEBP обрабатываются и уменьшаются перед отправкой

## Остальные разделы
- [ ] Поля «О вас» необязательные
- [ ] Поля «Знакомства» необязательные
- [ ] Поля «Формат встреч» необязательные
- [ ] На проверке видны введённые ответы
- [ ] «Изменить» возвращает в нужный раздел

## Отправка
- [ ] Оба согласия обязательны
- [ ] После нажатия появляется «ОТПРАВЛЯЕМ…» и повторное нажатие блокируется
- [ ] Заявка появляется в «Участники»
- [ ] Заявка появляется в «Сайт — RAW»
- [ ] Фото появляется в папке фотографий
- [ ] В «Участники» есть рабочая ссылка на фото
- [ ] В «Сайт — Логи» статус OK / готово
- [ ] Desktop получает экран «Ваша заявка отправлена»
- [ ] Android получает тот же экран
- [ ] На экране показывается тот же ID, который записан в базе
- [ ] При серверной ошибке показывается ошибка, а не ложный успех

## Состояние формы
- [ ] Полное обновление страницы открывает чистую анкету
- [ ] Переход «Назад» внутри формы не стирает введённые поля
- [ ] Политика конфиденциальности открывается в новой вкладке, исходная анкета остаётся заполненной
- [ ] После успешной отправки форма больше не позволяет случайно отправить ту же заявку повторно

Только после прохождения всех пунктов V2 заменяет текущую форму на главной странице.
